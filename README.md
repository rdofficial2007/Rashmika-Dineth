# Rashmika Dineth — Creative Professional Portfolio

A modern, high-end portfolio website inspired by [hanson-wu.com](https://hanson-wu.com/) with interactive horizontal scrolling, cinematic mist layers, film grain animation, 3D rotating tag clouds, and embedded video showreels.

## 🌟 Features

- **Hero Landing**: Dramatic typography reveal ("RASHMIKA'S PROFESSIONAL PORTFOLIO"), atmospheric drifting fog/mist layers, and animated film grain.
- **Intro Loader**: Signature glowing yellow/gold expanding bubble with live progress counter (0% to 100%).
- **Services Showcase**:
  - **Promotional Videos**: Embedded YouTube player with company ad showcase.
  - **Logo Intros**: Embedded YouTube player with animated brand identity showreel.
  - **Event Posters**: Featured high-resolution visual artwork ("විදුරැත් නින්නාද / Vidurath Ninnada").
- **Interactive About Popup**:
  - Clickable profile photo (sidebar & mobile header) and "About Me" menu link.
  - Dark glassmorphism card with direct Call (`078 909 91 71`) and WhatsApp buttons.
  - Skills badges and social media shortcuts.
- **Horizontal Scroll & Keyboard Navigation**:
  - Mouse wheel smooth horizontal scrolling on desktop.
  - Keyboard arrow navigation (`ArrowRight` / `ArrowDown` forward, `ArrowLeft` / `ArrowUp` backward, `Space`, `PageDown`, `PageUp`, `Home`, `End`).
  - Seamless vertical responsive layout for mobile and tablet devices.
- **3D Interactive Tag Cloud**:
  - Software sphere (Photoshop, Illustrator, Premiere Pro, Audition, CapCut, Filmora, Affinity, AI Video).
  - Gentle, readable rotation speed with mobile touch drag/swipe support.
- **Contact & Footer**:
  - Rotating SVG circular text ("CONTACT ME • CONTACT ME • CONTACT ME").
  - Social channels (Instagram, Facebook, X, TikTok) with hover state animations.

## 🚀 How to Run

Simply open `index.html` in any modern web browser (Google Chrome, Microsoft Edge, Mozilla Firefox, or Brave):

```
C:\Users\RD OFFICIAL\.gemini\antigravity\scratch\portfolio-website\index.html
```

No build tools, Node.js, or servers required!
